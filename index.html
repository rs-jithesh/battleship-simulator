ℹ️ Why WebRTC Local Wi-Fi Instead of Raw Browser Bluetooth?

Web browsers (Chrome/Safari/Edge) restrict the Web Bluetooth API to Central Mode only (connecting to Bluetooth sensors/peripherals) and do not allow a webpage to broadcast as a GATT Peripheral Server for phone-to-phone pairing. However, browsers do support direct device-to-device WebRTC P2P DataChannels!
